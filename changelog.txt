Epic RPF — Changelog
====================


Version 5.0.0  (2026-07-02)
---------------------------

New:
  * Archive protection (locking) — right-click any root .rpf and choose "Lock (protect)"
    to encrypt the whole archive (AES-256) at rest, so neither CodeWalker, OpenIV nor
    GTA V can read it directly. An optional password additionally gates opening/
    extracting the contents in Epic RPF itself — it never blocks the game from running
    the file. Fully reversible with "Unlock".
  * Opening cracked / tampered archives — when an .rpf has been deliberately tampered
    (e.g. a bogus encryption flag) so GTA V still loads it but CodeWalker/OpenIV refuse
    to open it, Epic RPF now brute-forces the real table-of-contents encryption and
    recovers the full file list anyway — including nested archives protected the same
    way — without modifying the file on disk.
  * Archive Fix — a new 🛠 toolbar button (and a right-click "Archive Fix" on any .rpf)
    rebuilds/defragments archives so GTA V loads them cleanly after heavy in-app
    editing, the same job as the ArchiveFix-for-GTA tool. Every rebuild backs up the
    archive first and automatically rolls it back if the result doesn't re-open
    cleanly, so a bad rebuild is never left on disk; "Archive Fix: ON" keeps
    auto-fixing every further change for the rest of the session.
  * rpfcli — a new headless command-line tool for scripts and coding agents: ls, find,
    info, cat, get and put work across the whole GTA install, including inside .rpf
    archives and NG-encrypted ones (writes auto-derive the encrypt tables, cached after
    the first use), plus epic create/inspect/install and lock/unlock/lockinfo.
  * .ybn collision files now open in the 3D viewer — the bounds (triangle meshes, box
    polys and primitive shapes) render as a flat-shaded, palette-coloured model.

Fixes:
  * Hardened Archive Fix's rollback path: if restoring the pre-rebuild backup itself
    failed (e.g. the archive was locked by another process the whole time), the tool
    used to silently report the file as "left unchanged" and could delete the one
    clean backup copy in the process. It now keeps the backup on disk and reports the
    failure clearly with the backup's filename so a bad rebuild is always recoverable.
  * The background "Archive Fix: ON" auto-fix pass now checks that an archive isn't
    locked by another program before rebuilding it (the manual right-click fix already
    did); a locked archive is skipped and stays queued for the next successful pass
    instead of failing mid-rebuild.


Version 4.2.6  (2026-06-27)
---------------------------

New:
  * .rpf archives now have their own desktop icon — a distinct gold "archive box"
    — just like the other GTA file types, instead of a generic file icon.
  * Double-clicking a .rpf opens Epic RPF and mounts its folder, so you can browse
    the archive straight away (an .rpf is far too large to open as a single raw
    file, so it's mounted and shown in the tree instead).
  * File-type icons are now applied right after installation — you no longer have
    to launch the app once for them to appear — and they're removed again when you
    uninstall, with the Windows icon cache refreshed both times so the change shows
    immediately (no logoff or Explorer restart needed).


Version 4.2.5  (2026-06-27)
---------------------------

Fixes:
  * Uninstall now fully removes the program folder even when Epic RPF is still
    running. The uninstaller force-closes the app (and the background WebView2
    processes it spawns) first, so its .exe and DLLs are no longer locked and left
    behind with a "could not delete all files" message.


Version 4.2.4  (2026-06-27)
---------------------------

New:
  * Uninstall now deletes the ENTIRE Epic RPF folder, including the files the app
    and the bundled CodeWalker create while running (caches, configs, logs) that a
    normal uninstall would leave behind. Your GTA mod backups are untouched — they
    live in the GTA folder, not the install folder.


Version 4.2.3  (2026-06-27)
---------------------------

New:
  * Full keyboard control of the file list. Use the Up / Down arrows to move the
    selection (it wraps around from the bottom back to the top, and vice-versa),
    Enter to open, Backspace to go up a folder, Home / End and Page Up / Page Down
    to jump, and just start typing a name to jump to it. Shift+arrows extend the
    selection and Ctrl+A selects everything. The mouse's Back / Forward side
    buttons navigate history. The explorer is now fully drivable without a mouse.
  * Windows-standard cut / copy / paste. Ctrl+C, Ctrl+X and Ctrl+V (and the
    right-click menu) copy or move files and folders — even across archives. Cut
    items are dimmed until you paste; a paste that would clash is auto-renamed
    ("name - Copy") so nothing is ever overwritten, and a cut is undoable.


Version 4.2.2  (2026-06-26)
---------------------------

Fixes:
  * The window's Minimize / Maximize / Close buttons are always visible now. With
    the extra toolbar buttons they could be pushed off the right edge at the
    default window size; the toolbar now adapts (the path box shrinks first and the
    buttons never wrap), the window controls are pinned, and the default window is
    a little larger.


Version 4.2.1  (2026-06-26)
---------------------------

Fixes:
  * Desktop icons — more file types now show their own icon (added .ynv, .yed,
    .yfd, .ypdb, .mrf, .yld and .gxt2), and the Windows icon cache is refreshed on
    update so a type that was stuck on the old shared icon (e.g. .ytd) now shows
    its correct one. Generic types (.txt/.xml/.ini/.lua/.cfg) are deliberately left
    alone.
  * Installer language — the language you pick on the installer's first page is now
    applied to the tool itself, so installing in (say) German starts Epic RPF in
    German. You can still change it any time in Settings. The installer now also
    offers French, Spanish, Italian, Dutch, Russian, Japanese and Portuguese.
  * Uninstall — uninstalling now removes everything Epic RPF created: all file
    associations and icons, saved settings, custom names, the trash, and the
    WebView2 cache. Nothing is left behind.


Version 4.2.0  (2026-06-26)
---------------------------

New:
  * Settings — a new "⚙ Settings" button in the toolbar opens a settings panel:
      - Themes: pick from Epic (the default), Dark, Light, Ultra dark, and
        Night (OLED) — a pure-black theme for OLED screens. Click a preview tile
        to switch instantly.
      - Accent colour: choose from preset swatches or pick any custom colour;
        buttons, highlights and the loading bar follow it.
      - Language: the interface is now translatable — English, Spanish, French,
        German, Portuguese, Italian, Dutch, Russian, Chinese and Japanese. It
        switches live, no restart needed.
      - Round edges: Sharp, Rounded or Extra rounded — this now also rounds the
        ACTUAL window corners, not just the controls.
      - Window outline: turn on a customizable outline around the whole window and
        set its colour and thickness; it follows the rounded corners.
    Every setting is saved and re-applied the next time you open the app.
  * Per-file-type desktop icons — each GTA file type (.ydr, .ytd, .ypt, .meta,
    .ymap, .ycd, …) now shows its OWN icon on the desktop and in Explorer — the
    same icon it has inside the tool — instead of every type sharing one app icon.
    The icons are high-resolution (crisp at every size, up to 256px) and Epic RPF
    is set as their default handler so the icons appear automatically.


Version 4.1.0  (2026-06-26)
---------------------------

New:
  * Export textures straight out of a .ytd / .ypt. Drag any texture from the
    texture grid to Explorer, the desktop or another app and it's saved as a raw
    .dds — the texture's own data, untouched (original format + mipmaps kept).
    Select several (click / Ctrl-click / Shift-click) and drag them all out at once.
  * Right-click a texture (or a multi-selection) → Export as → PNG, JPEG, or
    Raw DDS. One texture opens a Save dialog; several ask for a destination folder
    and write each into it.
  * Saving a texture as DDS now lets you pick the mipmap levels (All, none, or an
    exact count) and the compression quality (Best / Balanced / Fast). The RGBA
    format is clearly labelled "uncompressed" for a lossless export.


Version 4.0.0  (2026-06-25)
---------------------------

New:
  * CodeWalker world editor — a new "🗺 CodeWalker" button in the toolbar opens
    the full CodeWalker map editor: fly around the GTA V world, and select and
    export world objects and interiors (MLOs), all loaded from your real game
    files. It ships as a companion tool alongside Epic RPF.
  * Reload — a new "⟳ Reload" button force-re-reads every archive from disk, so
    you can refresh the whole view on demand if something looks out of date.
  * Multi-select textures — in a .ytd you can now click / Ctrl-click / Shift-click
    several textures and delete them all at once (or just press Delete). Textures
    are tracked by identity, so the right ones are always removed.
  * Live updates — when you edit a file inside an archive, its size in the file
    list now updates instantly, with no manual refresh.
  * Archive sizes — .rpf archives show their real file size in the list (e.g. your
    update.rpf shows ~2 GB) instead of a plain item count.

Fixes:
  * Editing textures inside archives is now reliable. Adding, replacing or
    deleting a texture in a .ytd — including inside the large update.rpf — no
    longer intermittently corrupts the file or shows it as raw hex afterwards.
    The cause was the live file-watcher reloading the archive in the middle of a
    write and invalidating the view; writes are now fully isolated, every file is
    re-read from its live location on open, and a reload no longer leaves stale
    file tabs behind. Editing the same .ytd several times in a row is solid.
  * Renaming a .rpf archive now works (it used to be refused outright). Encrypted
    (NG/AES) archives are converted to an editable form first, behind a clear
    confirmation.
  * Dragging a file into an archive is much faster — only the affected archive is
    re-read, instead of remounting everything.
  * The XML / meta editor (e.g. content.xml) no longer opens with a broken,
    unscrollable view.
  * Double-clicking a data folder immediately after mounting no longer
    occasionally fails to open it.


Version 3.1.2  (2026-06-16)
---------------------------

Fixes:
  * You no longer get kicked back to the GTA V root when a file changes on disk
    (e.g. dragging in a new .rpf, or any external change that triggers a reload).
    The explorer now stays exactly in the folder you were in — re-finding it in
    the freshly reloaded archives — instead of resetting to the top.
  * Importing an exported XML that has embedded textures now works. Drawable /
    resource XML (.ydr / .ydd / .yft / .ypt) reference their textures by name and
    expect the .dds files alongside; the import now reads the XML straight from
    disk and pulls those textures from the sibling folder (the way CodeWalker
    does), so it no longer fails with "Object reference not set to an instance of
    an object". Textureless metas still import as before.


Version 3.1.0  (2026-06-14)
---------------------------

Fixes & safety:
  * Write protection — every change written into a .rpf archive is now validated
    first and refused, with a clear reason, if it would corrupt the archive or
    crash the game. This catches writes that would push a file past the RPF
    ~4.3 GB resource / ~8.6 GB offset limit (which silently truncates the file
    table and wrecks the whole archive), and .ypt/.ytd resources carrying an
    invalid / sRGB texture format. A bad edit can no longer silently break
    update.rpf.
  * Importing XML / meta is far more robust. Files whose name doesn't carry the
    full format hint (e.g. a PSO meta saved plainly as .xml) now convert correctly
    instead of failing with "Object reference not set to an instance of an
    object", and a genuine type mismatch now reports a clear, actionable message.
  * Importing a PNG (or other image) as a texture keeps its real colours. Images
    are now decoded directly with straight alpha instead of through the browser
    canvas, which was zeroing the colour of transparent pixels and could turn an
    image solid black.


Version 3.0.0  (2026-06-14)
---------------------------

New:
  * Animations — play GTA animations (.ycd) right in the model viewer. The new
    Anims tab automatically finds the animation dictionaries that belong to a
    model, lists every clip, and plays them with play/pause, a scrub bar, speed
    control and a live skeleton overlay. You can also browse to any .ycd yourself.
  * Show character — tick "Show character" on a weapon and a full freemode
    character is loaded holding it, so movement / aim / reload / idle clips play
    on a whole body instead of a floating gun. A live "Grip adjust" panel
    (position + rotation sliders, remembered between sessions) lets you seat the
    weapon exactly in the hand.
  * Vehicle additions — toggle optional extra parts (bull-bars, roof racks and the
    like) on and off from the Materials tab.
  * Much better 3D rendering — corrected texture orientation, proper Phong shading
    with normal / specular / emissive maps, and an editable shader-parameters
    panel whose changes save straight back into the model.
  * Skeleton tab — browse a model's bone hierarchy with a live overlay, and point
    the viewer at your own .ytd files when you want different textures.

Fixes:
  * Exporting as XML no longer fails on loose resource files that are almost pure
    skeleton (some .yft models); and when an export does fail it now reports the
    real reason instead of a generic "export failed".


Version 2.0.0  (2026-06-12)
---------------------------

New:
  * Open any supported file by double-clicking it in Windows. If Epic RPF is
    already open the file appears in a new tab; if it's closed, it launches in a
    clean single-file viewer (the right renderer for that file) — and stays fully
    editable. File types are registered automatically on first run (no admin).
  * Rename files, folders and items inside archives — right-click > Rename, or
    press F2. (.rpf archives are intentionally not renamable; they're keyed by
    filename and renaming one breaks it.)
  * Rubber-band selection — drag a box over empty space in the file list to
    select everything it touches (hold Ctrl to add to the current selection).
  * Delete individual textures from a .ytd / .ypt — right-click a texture >
    Delete texture; the dictionary is rebuilt and saved in place.
  * One-click .epic mod extensions: package mods into a single encrypted .epic
    file that installs by dragging it onto the app (auto-backs up every changed
    file). Build them in-app via the Extension menu.
  * Much faster .epic packaging: creating and opening an extension now streams the
    payload instead of re-compressing it, so a large file (e.g. a ~2 GB update.rpf)
    packs in a few seconds instead of minutes — with a progress bar while it works.
  * Export as XML from the right-click menu (works on multi-selection); drop the
    .xml back in to re-import it in the original binary format. Extracting a file
    you're viewing as XML now asks whether you want the normal or XML format.
  * Native OS drag-out: drag files (incl. multiple) straight out of the app to
    Explorer, the desktop, or any other program.

Cosmetic:
  * Custom icon for .epic files — a distinct package icon, not the app icon.
  * Folders named "epic" get a custom icon and a glowing, animated name.

Fixes:
  * The "epic" folder glow is no longer clipped on the right edge.
  * Various texture/save robustness fixes (NG-encryption handling, stale-entry
    corruption, sRGB DDS).


Version 1.0.0  (2026-06-10)
---------------------------

  * Initial release. Mount and browse GTA V .rpf archives (Gen8), with a fast
    HTML/WebGL interface.
  * 3D model viewer (.ydr/.ydd/.yft/.ypt) with orbit camera, LODs, materials and
    resolved textures.
  * Texture viewer/editor for .ytd / .ypt — preview, replace/import images and
    DDS, drag-and-drop import.
  * Built-in XML/meta editor (Monaco) with binary-meta <-> XML round-trip and
    save back into the archive.
  * Scaleform (.gfx) viewer, global search, extract / extract-all, create
    folder / RPF / YTD, delete-to-trash with undo, and live filesystem watching.
  * Self-contained installer (bundles the .NET runtime + WebView2 bootstrapper).
